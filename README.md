# ishan-portfolio

My personal site: [ishan-portfolio-xi-sage.vercel.app](https://ishan-portfolio-xi-sage.vercel.app)

A single page built with Next.js 16, Tailwind CSS 4 and shadcn/ui. The content lives in `src/app/page.tsx` as plain arrays (`experience`, `education`, `certifications`, `projects`), so updating the site usually means editing one of those.

```bash
npm install
npm run dev    # http://localhost:3000
npm run build
npm run lint
```

Deployed on Vercel from `master`.
